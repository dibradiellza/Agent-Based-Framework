# Agent-Based-Framework
This repository contains the implementation accompanying my master's thesis on autonomous cryptocurrency trading strategy development using Large Language Models (LLMs). Inspired by Karpathy's AutoResearch paradigm, the proposed framework iteratively generates, evaluates, and refines trading strategies through interaction with a fixed backtesting environment, retaining only modifications that improve predefined performance criteria.

Two framework architectures were implemented and evaluated:

Single-Agent Framework
Dual-Agent Framework, consisting of an Explorer Agent and a Risk Manager Agent

The objective of this project is to demonstrate the feasibility of autonomous strategy development using LLM agents rather than to develop a production-ready trading system. The framework provides a foundation for future research on agent-based financial optimization systems.
